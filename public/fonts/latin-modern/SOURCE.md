These are the 72 unmodified OpenType text fonts from Latin Modern 2.005.

Copyright 2003–2021 Bogusław Jackowski and Janusz M. Nowacki, on behalf of TeX Users Groups.

Source: https://mirrors.ctan.org/fonts/lm.zip
Project: https://www.gust.org.pl/projects/e-foundry/latin-modern/

The complete upstream work is available from the source above. This distribution includes the OpenType text fonts, the upstream README, manifest and GUST Font License in `v2.005/`. It omits the upstream Type 1, TeX and math assets.

`src/lib/recoveryFonts.json` pins each font's PostScript name, same-origin path and SHA-256 digest. The build and browser verify these digests. Changes require a new versioned asset path and updated manifest; do not overwrite immutable assets.

Fonts are downloaded only on a failed original-font edit, or when the user enables the optional offline app cache. No document processing occurs on the font server.
